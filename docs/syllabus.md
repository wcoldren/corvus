# Latin Syllabus

## How the course works

About 80 daily lessons of roughly 10 minutes take you from zero to reading Aquinas and Seneca with a dictionary. At one lesson a day with some missed days, that is about four months.

- **Each lesson:** one new idea, a short story passage, 3–5 exercises, and 5–10 new flashcards.
- **Pronunciation:** Ecclesiastical throughout (*c* before e/i = "ch", *g* before e/i = "j", *ae* = "eh", *ti* + vowel = "tsee").
- **Review rhythm:** a quick quiz on older material every 5th lesson, and a full review lesson at the end of each unit.
- **Chats:** one chat per lesson in this project. Open each by pasting the previous lesson's recap.
- **Flashcards:** daily reviews in your web app take care of memorization, so lessons can stay short and keep moving.
- **Pace rule:** a missed day changes nothing. If reviews pile up, do a review day before the next new lesson.

## The story: *Fabula Felicis*

Felix, a novice apothecary at the mountain abbey of *Mons Ferri*, discovers that the old alchemical formulas really work, but only when spoken in flawless Latin. The fantasy rule doubles as the grammar lesson: say *aquam* where *aqua* belongs and the flask boils over.

- **Felix** (*felix*, "lucky"): eager, careless with endings, learning exactly what you are learning.
- **Frater Anselmus:** the old master apothecary; speaks slowly and correctly, then later in long scholastic sentences.
- **Corvus:** a raven who talks only in Latin, mocks bad grammar, and quotes Seneca at bad moments.
- **The scriptorium:** where Felix copies Cicero and Seneca by day, bringing in classical Latin.
- **The Office:** the sung prayers at fixed hours, bringing in Church Latin.

Passages start at 2–3 sentences and grow with each unit. The fantasy stays light: the magic is a reason for correct grammar to matter, never a replacement for the real texts we read later.

## Flashcard app

Each lesson ends with a card file you commit to the repo, and the app unlocks those cards in the next review. Plan: a web app on GitHub Pages, added to the iPad home screen, scheduled with FSRS (the algorithm modern Anki uses).

- **Card files:** one per lesson, e.g. `cards/lesson-02.json`, each card tagged with its lesson and unit so quizzes can pull from older material.
- **Card types:**
  1. Vocab, Latin → English and English → Latin, with genitive and gender on nouns
  2. Concept: "What does the dative do?"
  3. Ending cells: "1st declension, genitive plural → ?"
  4. Parsing: "*aquarum* → case and number?"
  5. Typed answers, so endings are checked letter by letter
- **Saving progress:** review history lives on the iPad, with a one-tap export as backup; cloud sync can come later.
- **Build:** you set up the repo; Claude Code writes the app. Card files from Lesson 1 onward get backfilled.

App and repo name: **corvus**.
